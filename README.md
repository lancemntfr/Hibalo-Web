# Hibalo-Web

Landing page for Hibalo, a capstone project of the Polytechnic University of the Philippines. Hibalo is an Android app that translates between Hiligaynon and Filipino and teaches Hiligaynon.

## Run locally

It's plain HTML, CSS and JavaScript, so there's no build step. From the project folder:

```sh
python -m http.server 8000
```

Then open http://localhost:8000. VS Code Live Server works too.

## Structure

```
index.html   the page
css/         styles
js/          gallery tabs, FAQ and the dropdown cards
assets/      images, icons and the font
```
